      Before your first scan

      • Everything stays on this PC. Xylem has no network code and never uploads anything about your files.
      • Fast Scan is read-only. Windows asks for admin permission; a small helper reads the drive's file table for about 1–5 seconds, hands the result to Xylem, and exits.
      • Deleting is reversible. Everything goes to the Recycle Bin, and Windows and app folders are locked.

      Security & privacy

      Offline
      Xylem's code makes no network connections. The page is locked by a Content Security Policy that only allows its own files.
      Read-only disk access
      The drive is opened for reading only. Xylem contains no code that writes to the disk.
      Admin, briefly
      Only the scan helper runs as admin, after you approve the Windows prompt. It exits when the scan ends, usually in 1–5 seconds.
      Safe delete
      Everything goes to the Recycle Bin. System and program folders are locked in the app's backend, not just hidden in the UI.
      Honest note
      The window is drawn by Microsoft WebView2, which can contact Microsoft for its own updates and configuration, like Edge does. Xylem's data never goes there.
