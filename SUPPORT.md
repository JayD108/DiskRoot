# Getting help

- **How do I…?** Start with the [README](README.md) and [Features and development](docs/FEATURES-AND-DEVELOPMENT.md): every feature, how to use it and what happens underneath. Inside DiskRoot, **Help → Take the tour** and **Ctrl+K** (every command and folder, one search) help too.
- **Command line:** [docs/CLI.md](docs/CLI.md).
- **Something doesn't work:** open a [bug report](https://github.com/JayD108/DiskRoot/issues/new?template=bug_report.yml). Please include the DiskRoot version (Help → About) and your Windows version.
- **An idea:** open an [idea / feature request](https://github.com/JayD108/DiskRoot/issues/new?template=feature_request.yml).
- **A security problem:** report it privately, see [SECURITY.md](SECURITY.md).
- **"Windows protected your PC":** releases aren't code-signed yet; click **More info → Run anyway**, and check the download against `SHA256SUMS.txt` on the release page.

DiskRoot is made by volunteers: answers can take a few days. Please keep to the [Code of Conduct](CODE_OF_CONDUCT.md).
